# 先读世界 · Read the World

去一个地方之前，先把它的书和片看完。

🔗 **在线地址：<https://judy2026797.github.io/ExploreTheWorld/>**

手机直接打开就能用，点一下圆圈勾进度，随时新增想去的国家和博物馆。

---

## 这是什么

一份「旅行前置阅读清单」。按**大洲**和**博物馆**两个维度组织，每个地方挂两栏内容：

- 📚 **书籍** —— 出发前该读的
- 🎬 **纪录片** —— 出发前该看的

每条都能点圆圈打进度：`未开始 → 进行中 → 已完成`。

预置内容：**11 个国家 + 14 家博物馆，共约 130 个书影片目**，覆盖亚洲、欧洲、非洲、美洲、大洋洲。

## 怎么用

| 操作 | 说明 |
|---|---|
| 点大洲 / 博物馆的标题行 | 收起或展开整个分区 |
| 点某个国家 / 博物馆那一行 | 展开看它的书单和片单 |
| 点条目左边的圆圈 | 循环切换 `未开始 → 进行中 → 已完成` |
| 右上角「＋ 新增国家」/「＋ 新增博物馆」 | 按钮文案跟着当前分区自动变 |
| 搜索框 | 搜国家、城市、书名、片名、作者都能命中 |
| 顶栏 tab | 按大洲筛，或切到「🏛 博物馆」只看馆 |
| 底部「导出备份」 | 存一份 JSON，换设备时「导入备份」恢复 |

## 数据存在哪 ⚠️

**存在你当前这台设备的浏览器里**（`localStorage`），没有服务器、不上传任何数据。

这意味着：

- ❌ 换手机、换电脑、换浏览器，**内容不会自动同步**
- ✅ 用底部「导出备份」存 JSON → 到新设备「导入备份」搬过去
- ✅ 勾选进度、自己新增的国家和条目，都会一起存、一起导出

> 浏览器缓存被清理，数据也会丢。重要的改动建议随手导出一份备份。

## 文件结构

```
index.html    ← 整个应用（样式 + 逻辑 + 种子数据全内联，无任何依赖）
.nojekyll     ← 告诉 GitHub Pages 跳过 Jekyll 处理
README.md     ← 本文件
```

单文件，双击 `index.html` 也能在本地直接用（Chrome 支持 `file://` 下的 `localStorage`）。

## 部署

GitHub Pages，`main` 分支根目录直出。改完 `index.html` 推上去，等约一分钟生效。

```bash
git add -A && git commit -m "update" && git push
```
